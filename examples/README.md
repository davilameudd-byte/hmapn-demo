# Arquivos de exemplo

Todos os materiais, setores, fornecedores e números desta pasta são fictícios.

- `estoque-ficticio.csv`: seis situações de cobertura, com valor total esperado de R$ 1.252,00 e estimativa mensal de R$ 450,00.
- `mensal-ficticio.csv`: duas linhas de consumo mensal para testar o reconhecimento do formato. A presença de dados mensais não transforma a estimativa do painel em consumo realizado.

No painel local, abra Importações e selecione um arquivo. Também é possível copiar os arquivos para a pasta Entrada do servidor. O CSV usa ponto e vírgula como separador; números podem usar vírgula decimal.

A data da posição é a data de modificação do arquivo. Para uma operação real, confirme essa data com o relatório de origem. Os indicadores de cobertura usam os limites configurados no servidor.
