SISTEMA HOSPITALAR

API direta

Não configurada

Depende de um endpoint e acesso liberados pela TI e pelo fornecedor. Nenhum acesso direto ao SALUX é realizado.

Do relatório ao indicador

  1. Exporte uma posição no SALUX.
  2. Salve o arquivo na pasta monitorada ou envie pela versão local.
  3. Confira a importação e acompanhe saldo, cobertura e histórico.

Python e SQLite fazem o processamento no computador. O código não exige assinatura de serviços. A demonstração pública usa somente dados fictícios.
