# HMAPN — Demonstração Web

Demonstração estática do painel de inteligência logística do Almoxarifado HMAPN, compatível com navegador no celular e no computador.

**Atenção:** todos os indicadores e materiais apresentados são fictícios. Esta demonstração não consulta o SALUX e não acessa dados reais do hospital.

## Acesso público via GitHub Pages

1. Abra **Settings → Pages** deste repositório.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Selecione **main** e **/(root)**, depois **Save**.
4. Após a implantação, acesse: https://davilameudd-byte.github.io/hmapn-demo/

## O que está incluído

- `index.html`: interface demonstrativa estática e responsiva.
- Navegação entre visão geral, materiais, série histórica e importações.

## Não incluído

Servidor Python, banco SQL, leitura de pastas locais, arquivos reais do SALUX ou atualização automática. Esses recursos fazem parte do sistema local e exigem uma infraestrutura própria com controle de acesso.

**Privacidade:** nunca publique relatórios reais do hospital, identificadores de pacientes, credenciais, bancos de dados ou caminhos internos neste repositório público.
